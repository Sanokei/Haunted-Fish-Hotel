# City facade sources

All assets are CC0 or public domain. No attribution is legally required; it is listed for provenance.

Each facade `X` in `Facades/` has three files: `X_Albedo.jpg` (cropped, power-of-two original), `X_Night.jpg` (darkened, cool-tinted, with the lit windows already baked in warm) and `X_EmissiveMask.png` (8-bit grey; white = lit window, ~35% of auto-detected windows). Use the mask as the Emission map (tint warm yellow) over either albedo. Window detection is automatic, so a few masks have small specks or miss windows (ACG_Facade019A/020A have very few lit windows).
